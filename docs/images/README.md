# Capturas de Filmma

Capturas reales de la interfaz con el proyecto ficticio «La última función · Demostración». Imágenes de personajes creadas con IA y clips técnicos locales; no son prueba de generación en Google. No contienen códigos de enlace, cuentas de Google ni proyectos de producción. Los PNG originales se conservan localmente en `output/google-browser/`.

Las capturas `filmma-refined-editor.jpg` y `filmma-refined-screenplay.jpg` muestran la revisión de interfaz de octubre de 2026. `filmma-elevenlabs-controls.jpg` utiliza un catálogo de voces simulado, rotulado en la guía; no acredita una cuenta conectada ni una síntesis de ElevenLabs. Sus fuentes de revisión se conservan en `output/qa/`, fuera de Git.
